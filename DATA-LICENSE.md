# SponsorBlock-derived metadata

Some initial candidate boundaries were informed by [SponsorBlock](https://sponsor.ajay.app/). SponsorBlock data and segment metadata derived from it are provided under [Creative Commons Attribution–NonCommercial–ShareAlike4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), as documented in [SponsorBlock's database/API license](https://github.com/ajayyy/SponsorBlock/wiki/Database-and-API-License).

Attribution: SponsorBlock contributors. Per-round `researchAttribution` records retain the source and license. Runtime candidate metadata also links the relevant SponsorBlock API request. Changes include selecting/adjusting candidate boundaries using linked caption cues, setup-start audits, visual sampling, and20-second safety holds. The original SponsorBlock segment is not itself a verified brand-reveal timestamp.

This data license is separate from application-code licensing. Preserve attribution, noncommercial and share-alike requirements for that data. Third-party video/caption material and brand marks are not relicensed here. No audio/video files or full transcripts are distributed by this repository.
